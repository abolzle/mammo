# Critique packet

You are an independent reviewer. Answer the item yourself before reading the proposed key.

## Tasks
1. Choose your own answer from a–d.
2. Compare it to the proposed `correctChoiceId`. If they differ, explain why.
3. Name the most plausible competing answer and why a prepared technologist might pick it.
4. For each factual claim in the stem, key rationale, and explanation, cite an evidence id from this packet or mark the claim unsupported.
5. Flag any invented source, copied commercial wording, or clinical threshold that needs qualified review.

## Output JSON
```
{
  "itemId": "",
  "independentChoiceId": "a",
  "agreesWithKey": true,
  "competingChoiceId": "b",
  "unsupportedClaims": [],
  "needsQualifiedReview": false,
  "notes": ""
}
```

Agreement between models is an error screen, not proof. Source checking means the cited material actually supports the answer.
